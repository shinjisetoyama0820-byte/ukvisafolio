英国配偶者ビザを申請したいけれど、「必要書類が多くて何から始めればいいか分からない」と困っていませんか？

Stratovisa（ストラトビザ）は、英国ビザの申請に必要な書類を整理できるオンラインツールです。

書類のチェックリスト、ファイル管理、説明文の作成、提出用ファイルの整理などを一つのサービスで進められます。

この記事では、Stratovisaの使い方、料金、無料で始める方法、割引コード、利用するときの注意点を解説します。

## Stratovisaとは？何ができる？

Stratovisaは、英国のVISA FLOW AI LTDが運営するビザ申請書類の準備サービスです。

現在、主に次の3種類の英国ビザに対応しています。

- 家族ビザ（配偶者・パートナー）
- 就労ビザ（Skilled Worker）
- 学生ビザ（Student）

主な機能は次のとおりです。


| 機能 | 内容 |
| -------- | ---------------------------- |
| 必要書類リスト | 申請状況に合わせて書類を整理 |
| ファイル管理 | パスポート、銀行明細などを登録 |
| 進捗管理 | 準備済み・未準備の書類を確認 |
| AI文書作成 | カバーレターなどの下書きを作成 |
| チャット履歴整理 | LINE・WhatsAppの履歴を関係性の説明資料に整理 |
| ZIP出力 | 書類をまとめてダウンロード |


ただし、**Stratovisaは英国政府の公式申請サービスではありません。**

ビザの審査や申請代行、個別の法律相談を行うものではありません。

## Stratovisaの使い方【6ステップ】

### ① 無料でアカウントを作成する

まず、Stratovisaの公式サイトを開きます。

[Stratovisa公式サイト](https://stratovisa.com/en)

登録画面の案内に従ってアカウントを作成します。

無料で開始できますが、すべての機能が無料という意味ではありません。

### ② ビザの種類と申請状況を入力する

英国配偶者ビザを準備する場合は、家族ビザの配偶者・パートナー向けの項目を選びます。

続いて、次のような情報を入力します。

- 英国国内・国外のどちらから申請するか
- 扶養家族がいるか
- 収入や貯金の状況
- その他、必要書類の判断に関係する情報

入力内容をもとに、書類チェックリストが作られます。

### ③ 必要書類を確認する

例えば、英国配偶者ビザでは次のような書類が必要になる場合があります。

- パスポート
- 結婚を証明する書類
- 給与明細
- 銀行明細
- 勤務先の証明書
- 英語力を証明する書類
- 住居に関する書類

必要書類は申請者によって異なります。

また、英国配偶者ビザでは通常、年収£29,000以上という収入条件がありますが、貯金による補完や一部の例外もあります。

Stratovisaのチェックリストだけで申請資格を判断せず、英国政府の最新条件を確認してください。

[英国政府：配偶者ビザの条件](https://www.gov.uk/uk-family-visa/partner-spouse)

### ④ 書類を登録する

準備した書類を、対応する項目へアップロードします。

公式FAQによると、PDF、JPEG、PNGに対応しています。

また、画像形式の変換、画像の圧縮、PDFの破損確認などの機能もあります。

作業の途中で中断しても、入力した情報は保存され、後から再開できます。

ただし、実際に英国政府へ提出するときは、提出先が指定するファイル形式や容量を確認してください。

### ⑤ AIで説明文を作成する

Stratovisaには、入力した情報からカバーレターや補足説明文を作る機能があります。

カバーレターとは、申請内容や提出書類を説明する文章です。

AIが作成した文章は、提出前に必ず確認してください。

特に氏名、日付、収入、夫婦関係などの情報が、実際の証明書類と一致しているかが重要です。

なお、すべての配偶者ビザ申請でカバーレターが必須というわけではありません。

### ⑥ 書類をまとめてダウンロードする

準備が完了すると、書類をZIP形式でまとめてダウンロードできます。

ZIPとは、複数のファイルを一つにまとめる形式です。

公式FAQでは、完成したファイルに次の内容が含まれると説明されています。

- 申請者情報と書類一覧をまとめたPDF
- 種類別に整理された証明書類
- 作成した説明文
- 提出方法を説明するREADMEファイル

**ZIPファイルをそのまま英国政府に提出することはできません。**

正式な申請画面の指示に従って、必要なファイルを個別にアップロードします。

## Stratovisaの料金はいくら？

2026年11月4日に確認した公式FAQの料金は次のとおりです。


| ビザの種類 | 料金 |
| --------------- | ---- |
| 家族ビザ（配偶者・パートナー） | £179 |
| 就労ビザ | £79 |
| 学生ビザ | £49 |


英国配偶者ビザ向けの通常料金は**£179**です。

料金はビザの種類ごとの1回払いで、月額契約ではありません。

購入日から365日間利用でき、その間は書類の更新や提出用ファイルの再作成ができます。

365日を過ぎると、新しい提出用ファイルを作成するには利用権の更新が必要です。

なお、英国政府へ支払うビザ申請料や医療付加料（IHS）は別料金です。

[Stratovisa公式料金・FAQ](https://stratovisa.com/en/help)

## 無料でどこまで使える？

Stratovisaは無料で利用を開始できます。

公式サイトでは、無料で書類準備を始められることが案内されていますが、すべての機能を無料で利用できるわけではありません。

有料アクセスが必要な機能や、購入前に利用できる範囲は、実際の登録画面で確認してください。

## LINE・WhatsAppの履歴も整理できる？

はい。家族ビザ向けの機能として、LINEやWhatsAppのチャット履歴を整理できます。

夫婦が離れて暮らしている場合、連絡を取り合っていることが関係性を示す資料になる場合があります。

Stratovisaでは、会話履歴から関係性の経過を説明する文章や時系列の資料を作成できます。

ただし、夫婦間のすべての会話を提出する必要があるわけではありません。

英国政府は、婚姻証明書、同居を示す書類、共同生活に関する証拠なども案内しています。

チャット履歴の整理機能は任意です。

[英国政府：夫婦関係の証明](https://www.gov.uk/uk-family-visa/partner-spouse)

## 個人情報はどう扱われる？

Stratovisaでは、パスポートや銀行明細などの個人情報を含む書類を扱います。

公式FAQによると、アップロードした書類ファイル自体はAIサービスへ送信せず、利用者が入力した文章をAIによる文書作成に利用する仕組みです。

ただし、これはサービス提供者による説明であり、当サイトが独立して安全性を監査したものではありません。

利用前に、プライバシーポリシーと利用規約を確認してください。

## Stratovisaでビザ申請まで完了する？

いいえ。

Stratovisaが行うのは、申請書類の準備と整理です。

英国政府への正式な申請は、自分で行う必要があります。

また、Stratovisaは次のサービスを提供しません。

- 申請資格の法律上の判断
- 申請するビザの種類についての法律的助言
- ビザの許可・不許可の予測
- 英国政府への申請代行
- ビザ取得の保証

個別の法律相談が必要な場合は、英国で適切な資格を持つ移民アドバイザーや弁護士に相談してください。
