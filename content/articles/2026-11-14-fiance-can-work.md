# 【英国婚約者ビザ】英国婚約者ビザで働ける？アルバイト・リモートワーク・就職活動の注意点

> 編集用下書き。一次情報の確認と品質審査が終わるまで公開しない。

## 結論

日本から婚約者として英国に入る人は、式の前に仕事を続けられるかを先に見ておいた方がよいです。GOV.UK のパートナーページは、婚約者または予定しているシビルパートナーとして認められた期間は、働くことも、就学することもできない、と書いています。アルバイト、正社員、就学を、週の時間で分ける文は、そのページにはありません。書かれているのは、その期間はできない、ということです。

結婚したあと、英国内から出すパートナーとしての申請が承認されて初めて、その次の許可で就労の話になります。承認されたパートナーは、通常、働けて就学もでき、公的資金にはアクセスできない、とページは書いています。切り替えの申請を出しただけでは、婚約者の「働けない」が終わる、とは書かれていません。

確認日は2026年11月14日です。対象は、英国で式を挙げるまでの滞在で、仕事を続けられるかを見ている人です。

## 対象者と必要な準備

対象は、まだ結婚しておらず、婚約者としての許可で英国に入る人です。すでに配偶者としての許可を持っている人は、この「できない」の文の対象外です。配偶者として承認されたあとの働き方は、別の記事です。

渡英から式、切り替えの承認まで、英国での給与を家計に入れない前提で予定を組んでください。収入の £29,000 は、多くの場合、英国にいる相手の収入で見ます。申請者の日本の給与を、相手の海外雇用の枠に入れる、とはこのページには書かれていません。

## 必要書類

この記事は、就労のために雇用契約を新しく出す書類の束を足す話ではありません。申請の時点で示すのは、6か月以内の結婚、英語、収入です。就職先の内定書を、結婚予定の代わりにはしません。

切り替えのあと働くなら、その時点の許可が分かるもの（eVisa の share code など）が、雇用主の確認に使われます。婚約者の許可のまま share code を、雇用できる証明にする、とはページは書いていません。

## 手順

1. 許可の種類が婚約者かを、決定通知で見ます。
2. 到着から結婚、切り替えの承認まで、英国では働きません。就学も、ページはできないと書いています。
3. 日本の会社の仕事を英国から続けることを、例外だとはページは書いていません。リモートだけならよい、という文もありません。
4. 結婚後、英国内から切り替えます。申請料は確認日時点で1人 £1,407、大人で2年6か月の IHS は £2,587.50 です。
5. 切り替えが承認されたあと、パートナーとしての就労の条件を、その決定で見ます。週の上限は、Family visa のページには書かれていません。

## 費用

働けない期間の生活費は、政府の申請料とは別です。日本からの申請は £2,064、IHS は £0 です。切り替えは £1,407 と £2,587.50 で、合計 £3,994.50 です。このあいだの家賃を、申請料が賄う、とは書かれていません。

## 書類の進み具合を、同じ画面で見るには

内定のメールと、結婚予定の資料を同じフォルダに入れると、就労の書類が結婚の証明に見えてしまいます。働く予定は、切り替えが承認されたあとの束に残してください。

Stratovisa（ストラビ）は、質問に答えると関係のない書類がリストから外れ、アップロードしたファイルの形式とサイズを確認し、カバーレターと Personal statement を作れます。Family では、LINE や WhatsApp の履歴から日付入りの記録を整え、最後に1つの ZIP にまとめられます。チェックリストと作業は無料で、カードは不要です。完成したパッケージは、このビザの一回払いです。揃えるのは申請に出す書類で、就職してよいかを決める画面はありません。

Stratovisa は書類整理ツールであり、移民アドバイザーではありません。申請資格の判断や移民に関する助言は行いません。書類の要件はすべて GOV.UK の公開ガイダンスに基づいています。英国政府や UKVI とは関係ありません。

## よくある質問

### 就職活動だけならよいですか

ページは、働けない、就学もできない、と書いています。面接や求人への応募を例外にする文はありません。就職活動なら許される、という例外は、このページには書かれていません。

### 無報酬ならよいですか

無報酬なら就労に当たらない、という文は、確認したページにはありません。ボランティアを何時間までならよいかという上限も、このページには書かれていません。

### 切替を出した翌日から働けますか

承認されてから、がページの流れです。申請中は、婚約者の許可の条件が残ります。申請中に条件が自動で変わる、とは書かれていません。

### National Insurance number はいつ取りますか

番号が無くても、働く権利を示せれば働き始められる、という説明は、すでに働く権利がある人の話です。婚約者の期間は、その権利が無い、とページは書いています。番号の取得手順は、切り替えの承認のあとです。
