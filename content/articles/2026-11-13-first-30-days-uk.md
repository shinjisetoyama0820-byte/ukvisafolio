# イギリス移住後に最初の30日でやること｜銀行・住居・医療・行政手続き

> 編集用下書き。一次情報の確認と品質審査が終わるまで公開しない。スコットランド、ウェールズ、北アイルランドはイングランドと違う手続きがある。

## 30日の公式チェックリストはない

渡英後30日の手続きを、GOV.UK が「30日チェックリスト」として1ページにまとめているわけではありません。確認できたものを、住む、診てもらう、働く、の順に分けると次のようになります。

在留資格は eVisa で、UKVI アカウントから見ます。口座の作成と eVisa の閲覧に料金はありません。アカウントに紐づいていれば通常すぐ見られ、最大24時間かかることがあります。仕事や住居で資格を示すときは、share code を発行します。渡航に使うパスポートは、eVisa に追加しておきます。

イングランドで家を借りるときは、家主に借りる権利（right to rent）を示します。英国・アイルランド市民でない人は、share code か、原本の移民書類です。ウェールズ、スコットランド、北アイルランドでは、この証明は不要と書かれています。

イングランドの GP は、誰でも無料で登録できます。NHS は、身分証、住所の証明、移民ステータスの証明を、登録のために求めていません。NHS number がなくても登録できます。

働く人は、National Insurance number がなければ、英国に来てから申請します。就労の権利を示せれば、番号が届く前に働き始められます。番号は eVisa、または BRP の裏に、すでに載っていることがあります。

Council Tax は、住居の評価帯、その自治体の税額、割引または免除があるかで決まります。低所得や給付がある人は、Council Tax Reduction を使える場合があります。

銀行口座について、政府が「この書類ならどの銀行も開設する」という単一の手順は出していません。銀行ごとに条件は違います。

確認日は2026年11月12日です。すでに英国に住む資格を持って到着した人向けです。観光の ETA で30日暮らす手続きではありません。

## 到着前に手元へ置くもの

対象は、配偶者・パートナーとしての Family visa、Skilled Worker、Student など、英国に滞在する許可を持って生活を始める人です。許可の種類によって、働けるかは違います。婚約者の6か月は就労も就学もできない、と Family visa のページは書いています。働けない許可の人が、National Insurance number を先に取る前提で動く場面はありません。番号の申請は、英国に住み、働く権利があり、働いているか、仕事を探しているか、採用のオファーがある人向けです。

到着前に手元へ置くものは、次です。

- 渡航に使ったパスポート
- ビザ申請で作った UKVI アカウントのメールとパスワード
- 住む住所。仮でも、GP には一時的な住所や診療所の住所で登録できる場合があります
- 働く予定があるなら、採用側が right to work を確認する方法。番号そのものが初日になければ始められない、とは書かれていません

日本の住民票、海外転出届、日本の年金と健康保険は、英国側の手続きとは別です。ここでは英国側だけを扱います。

## 手続きごとに求められるもの

窓口ごとに、公式ページが挙げているものは違います。一つのクリアファイルにまとめて、全部の窓口へ出すリストではありません。

eVisa を使うために求められるのは、UKVI アカウントです。持っていなければ作成します。作成と閲覧は無料です。share code は、新しい仕事や住居を借りるときに資格を示すために発行します。パスポートをアカウントに追加すると、その eVisa で渡航できる、と書かれています。

Right to Rent で、英国・アイルランド市民でない人が出せるのは、share code、または原本の移民書類です。家主は、share code の代わりに適格な移民書類を出したことを理由に断れない、と公式は書いています。この制度はイングランドだけです。

GP 登録で聞かれるのは、氏名、生年月日、住所という基本情報です。緊急連絡先、今かかっている GP があればその名前と住所、介護者がいればその名前と住所も聞かれます。NHS は、身分証、住所証明、移民ステータスを「登録のために求めていない」と書いています。子どもは16歳未満なら保護者が別の用紙で登録し、出生証明書などを求められることがあります。恒久の住所がない人は、一時的な住所、または診療所の住所を使える、と書かれています。

National Insurance number は、BRP の裏、または UKVI アカウントの eVisa に、すでに表示されていることがあります。ない場合に申請します。申請できるのは英国にいるときです。結果まで最大4週間と書かれています。

Council Tax で確認することは3つです。住居の評価帯、その帯に対する自治体の税額、割引または免除が使えるか。評価帯の変更事由として挙がっているのは、取り壊し、独立した住居への分割、在宅勤務の開始や終了、近隣の大きな変化などです。外国人だから免除、とはこのページには書かれていません。

銀行については、公式の書類リストがありません。口座を開くために right to rent の share code や賃貸契約を求める銀行がある、とここには書きません。それは銀行の内規であり、確認した政府ページの要件ではないためです。

## いつ、何をするか

30日のうち、公式に日数が書いてあるものと、書いていないものを分けます。

初日に近いもの。

1. UKVI アカウントに入り、eVisa が表示されるかを見る。最大24時間待つ場合があります。パスポートがアカウントになければ追加する。次の一時帰国で、追加前のまま出国しない。
2. イングランドで賃貸契約を結ぶ週なら、share code を発行して家主に示すか、原本の移民書類を示す。ウェールズ、スコットランド、北アイルランドでは、この証明は不要です。家主に求められたからといって、イングランドの制度だとは説明できません。

最初の週にできること。

3. 住む地域の GP を、NHS のサイトで郵便番号から探す。オンライン登録は約15分と書かれています。登録の連絡は、診療所が情報を受け取ってから通常5日以内ですが、それより長いことがあります。紙の用紙を診療所へ出してもよいです。診療所が断るのは、新規患者を受け付けていない、診療圏の外、過去にその患者名簿から外されている、という理由があり、14日以内に書面で理由が来ます。断られたら、地域の integrated care board、Citizens Advice、または Healthwatch に連絡できる、と NHS は書いています。
4. 住所が決まったら、その自治体の Council Tax を確認する。評価帯は自分では選べません。満額は、18歳以上が2人以上住む前提です。同居する配偶者とパートナーは連帯して支払います。18歳以上が自分だけで、ほかの成人がいない、またはほかの成人が学生などで人数に数えない（disregarded）場合は、請求額の25%引きです。世帯の全員が disregarded なら50%引きです。割引は自動では付きません。住むカウンシルへ申請します。低所得なら Council Tax Reduction が別にあります。

働き始める前後。

5. eVisa に National Insurance number がないかを見る。あれば、新しい番号は要りません。個人情報が変わっても、番号は一生同じです。
6. ない場合は、英国に来てから申請する。働く権利を示せれば、番号の到着前に就労を開始できます。雇用主への初日の案内には、権利の証明、給与振込の口座、身分の証明が含まれています。P45 がなければ starter checklist を使う、と公式の就職手順は書いています。日本の前職の源泉徴収票は、英国の P45 ではありません。
7. 番号の申請から4週間を超えて届かない、転居した、個人情報が変わった場合は、申請のヘルプラインに電話する。確認メール先頭の参照番号を手元に置く。

銀行には、この順番のどこにも政府の期限がありません。住居契約と eVisa が揃ったあとでも、銀行が断ることがあります。断られた理由の公式な再審査窓口は、確認した範囲にはありません。政府が「この銀行が断ったら次はここ」と案内している手順もありません。

学生で、大学が GP や住居の案内を出している場合、その案内は大学の手続きです。上の要件を狭めるものではありません。大学が身分証を求めることと、NHS が身分証を求めていないことは、同時にあり得ます。NHS の登録拒否理由に「身分証がない」は、確認したページにはありません。

## 費用

UKVI アカウントの作成、eVisa の閲覧、share code は無料と書かれています。

GP の登録は無料です。診察がすべて無料とは、この登録ページは書いていません。NHS の何が自己負担かは、登録とは別の話です。ここで書けるのは、登録に手数料はない、までです。

National Insurance number の申請に、確認したページは料金を書いていません。有料の代行を、政府の費用としては扱いません。

Council Tax は自治体と評価帯で変わります。全国一律の月額はありません。

Right to Rent の share code に、確認したページは申請者側の手数料を書いていません。

銀行の口座維持費は銀行が決めます。政府料金ではありません。

## 渡英前の書類と、到着後の手続き

到着後の手続きと、申請前に揃えた書類は別です。日本にいる間に、ビザごとの書類だけを一つのリストに置いておくと、到着後の手続きと混ざりません。

Stratovisa（ストラビ）は、質問に答えると関係のない書類がリストから外れ、アップロードしたファイルの形式とサイズを確認し、カバーレターと Personal statement を作れます。チェックリストと作業は無料で、カードは不要です。完成したパッケージは、ビザごとの一回払いです。

Stratovisa は書類整理ツールであり、移民アドバイザーではありません。申請資格の判断や移民に関する助言は行いません。書類の要件はすべて GOV.UK の公開ガイダンスに基づいています。英国政府や UKVI とは関係ありません。

### 紹介コード（35％オフ）

割引は Stratovisa のサービス料金です。英国政府のビザ申請料は対象外です。コードは、書かれた国にいる人だけ使えます。英国在住者向けのコードは、英国にいる人だけです。

リンクを開くと、コードが自動で適用されます。登録ページ、または登録後の支払いページにある「紹介コードをお持ちですか？」に、コードを直接入力することもできます。登録時、または支払い前なら追加できます。支払い後は追加できません。

日本在住者向け：紹介コード **TABIDACHI（旅立ち）**

[35％オフで登録する](https://stratovisa.com/ja/signup?ref=TABIDACHI)

英国在住者向け：紹介コード **ISSHONI（一緒に）**

[35％オフで登録する](https://stratovisa.com/ja/signup?ref=ISSHONI)

## よくある質問

### 住所が決まるまで、GP に登録できませんか

恒久の住所がなくても、一時的な住所、または診療所の住所で登録できる、と NHS は書いています。一時的な患者としての登録は最長3か月で、その用紙は診療所にあります。3か月後に、一時登録を再度出すか、恒久の登録をします。

### 銀行口座がないと、仕事を始められませんか

公式の初日の案内は、給与のために銀行の詳細を雇用主へ渡す、と書いています。口座がないと、その欄は埋まりません。一方、National Insurance number は、番号が届く前でも就労を開始できます。口座と番号は、別の話です。

### share code は一度出せば足りますか

仕事と住居の例が挙がっています。同じコードを両方に使い回せる期間は、確認した eVisa の概要ページには日数がありませんでした。日数は断定できません。使う直前に発行してください。

### スコットランドで家を借りるときも、share code は要りますか

Right to Rent の証明は、ウェールズ、スコットランド、北アイルランドでは不要と書かれています。家主が任意で在留資格を見たいと言うことと、この法的な証明は別です。

### 30日を過ぎたら、手続きできなくなりますか

30日は公式の期限ではありません。GP は到着後いつでも登録の対象で、National Insurance number は働き始めるときに出てきます。Council Tax は住み始めた住居に対して発生します。30日を一日でも過ぎたから無効、とは書かれていません。
