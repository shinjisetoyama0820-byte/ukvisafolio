# イギリス移住後に最初の30日でやること｜銀行・住居・医療・行政手続き

> 編集用下書き。一次情報の確認と品質審査が終わるまで公開しない。スコットランド、ウェールズ、北アイルランドはイングランドと違う手続きがある。

## 結論

渡英後30日の公式な必須リストを、GOV.UKが「30日チェックリスト」として1ページにまとめているわけではない。確認できた手続きを、住む・診てもらう・働く、の順に分けると次のようになる。

在留資格は eVisa で、UKVI アカウントから見る。口座の作成と eVisa の閲覧に料金は無い。アカウントに紐づいていれば通常すぐ見られ、最大24時間かかることがある。仕事や住居で資格を示すときは share code を発行する。渡航に使うパスポートは、eVisa に追加しておく。

イングランドで家を借りるときは、家主に借りる権利（right to rent）を示す。英国・アイルランド市民でない人は、share code か、原本の移民書類である。ウェールズ、スコットランド、北アイルランドでは、この証明は不要と書かれている。

イングランドの GP は、誰でも無料で登録できる。身分証、住所の証明、移民ステータスの証明は、登録のために必須ではない。NHS number が無くても登録できる。

働く人は、National Insurance number が無ければ英国に来てから申請する。就労の権利を示せれば、番号が届く前に働き始められる。番号は eVisa または BRP の裏に、すでに載っていることがある。

Council Tax は、住居の評価帯と、その自治体の税額と、割引または免除があるかで決まる。低所得や給付がある人は Council Tax Reduction を使える場合がある。

銀行口座は、政府が「この書類ならどの銀行も開設する」という単一の手順を公表していない。この記事では、銀行ごとの条件を断定しない。

確認日：2026年11月12日。対象は、すでに英国に住む資格を持って到着した人。観光の ETA で30日暮らす手続きではない。

## 対象者と必要な準備

対象は、配偶者・パートナーとしての Family visa、Skilled Worker、Student など、英国に滞在する許可を持って生活を始める人である。許可の種類によって、働けるかは違う。婚約者の6か月は就労も就学もできない、と Family visa のページは書いている。働けない許可の人が、National Insurance number を先に取る前提で動く必要は無い。番号の申請は、英国に住み、働く権利があり、働いているか、仕事を探しているか、採用のオファーがある人向けである。

到着前に手元へ置くものは、次である。

- 渡航に使ったパスポート
- ビザ申請で作った UKVI アカウントのメールとパスワード
- 住む住所。仮でも、GP には一時的な住所や診療所の住所で登録できる場合がある
- 働く予定があるなら、採用側が right to work を確認する方法。番号そのものは初日に必須ではない

日本の住民票の扱い、海外転出届、日本の年金と健康保険は、英国の30日リストには無い。日本側の手続きは別記事にする。この記事に混ぜて、英国の GP 登録の条件のように書かない。

## 必要書類

手続きごとの「求められるもの」は公式ページで次のとおり。一つのクリアファイルにまとめて全部の窓口へ出すリストではない。

eVisa を使うために必要なのは、UKVI アカウントである。持っていなければ作成する。作成と閲覧は無料。share code は、新しい仕事や住居を借りるときに資格を示すために発行する。パスポートをアカウントに追加すると、その eVisa で渡航できる、と書かれている。

Right to Rent で、英国・アイルランド市民でない人が出せるのは、share code、または原本の移民書類である。家主は、share code の代わりに適格な移民書類を出したことを理由に断れない、と公式は書いている。この制度はイングランドだけである。

GP 登録で必須とされているのは、氏名、生年月日、住所という基本情報である。緊急連絡先、今かかっている GP があればその名前と住所、介護者がいればその名前と住所も聞かれる。身分証、住所証明、移民ステータスは「登録のために必要ではない」と NHS は書いている。子どもは16歳未満なら保護者が別の用紙で登録し、出生証明書などを求められることがある。恒久の住所が無い人は、一時的な住所、または診療所の住所を使える、と書かれている。

National Insurance number は、BRP の裏、または UKVI アカウントの eVisa に、すでに表示されていることがある。無い場合に申請する。申請できるのは英国にいるときである。結果まで最大4週間と書かれている。

Council Tax で知ることは3つである。住居の評価帯、その帯に対する自治体の税額、割引または免除が使えるか。評価帯の変更事由は、取り壊し、独立した住居への分割、在宅勤務の開始や終了、近隣の大きな変化などとして例が挙がっている。外国人だから免除、とはこのページには書かれていない。

銀行については、公式の必須書類リストが無い。口座を開くために right to rent の share code や賃貸契約を求める銀行はある、とこの下書きでは書かない。それは銀行の内規であり、確認した政府ページの要件ではない。

## 手続きと注意点

30日を、公式に日数が書いてあるものと、書いていないものに分ける。

初日に近いもの。

1. UKVI アカウントに入り、eVisa が表示されるかを見る。最大24時間待つ場合がある。パスポートがアカウントに無ければ追加する。次の一時帰国で、追加前の状態のまま出国しない。
2. イングランドで賃貸契約を結ぶ週なら、share code を発行して家主に示すか、原本の移民書類を示す。ウェールズ、スコットランド、北アイルランドの住居では、この証明手順を家主に要求されているからといって、イングランドの制度だと説明しない。不要である。

最初の週にできること。

3. 住む地域の GP を、NHS のサイトで郵便番号から探す。オンライン登録は約15分と書かれている。登録の連絡は、診療所が情報を受け取ってから通常5日以内だが、それより長いことがある。紙の用紙を診療所へ出してもよい。診療所が断るのは、新規患者を受け付けていない、診療圏の外、過去にその患者名簿から外されている、という理由があり、14日以内に書面で理由が来る。断られたら、地域の integrated care board、Citizens Advice、または Healthwatch に連絡できる、と NHS は書いている。
4. 住所が決まったら、その自治体の Council Tax を確認する。評価帯は自分で選べない。満額は、18歳以上が2人以上住む前提である。同居する配偶者とパートナーは連帯して支払う。18歳以上が自分だけで、ほかの成人がいない、またはほかの成人が学生などで人数に数えない（disregarded）場合は、請求額の25%引きである。世帯の全員が disregarded なら50%引きである。割引は自動では付かない。住むカウンシルへ申請する。低所得なら Council Tax Reduction が別にある。

働き始める前後。

5. eVisa に National Insurance number が無いかを見る。有れば、新しい番号は要らない。個人情報が変わっても番号は一生同じである。
6. 無い場合は、英国に来てから申請する。働く権利を示せれば、番号の到着前に就労を開始できる。雇用主には、権利の証明、給与振込の口座、身分の証明が初日の案内に含まれている。P45 が無ければ starter checklist を使う、と公式の就職手順は書いている。日本の前職の源泉徴収票は、英国の P45 ではない。
7. 番号の申請から4週間を超えて届かない、転居した、個人情報が変わった場合は、申請のヘルプラインに電話する。確認メール先頭の参照番号を手元に置く。

銀行は、この順番のどこにも政府の期限が無い。住居契約と eVisa が揃ったあとでも、銀行が断ることがある。断られた理由の公式な再審査窓口は、この下書きの確認範囲には無い。複数の銀行を当たる以外の政府手順を書かない。

学生で、大学が GP や住居の案内を出している場合は、その案内は大学の手続きであり、上の法律上の要件を狭めるものではない。大学が身分証を求めることと、NHS が身分証を必須としていないことは、同時にあり得る。NHS の登録拒否理由に「身分証が無い」は、確認したページには無い。

## 費用

UKVI アカウントの作成、eVisa の閲覧、share code は無料と書かれている。

GP 登録は無料である。診察がすべて無料とは、この登録ページは書いていない。NHS の何が自己負担かは、別の医療記事で確認する。この30日の記事では、登録に手数料は無い、までにする。

National Insurance number の申請に、確認したページは料金を書いていない。有料の代行を政府の必須費用としては書かない。

Council Tax は自治体と評価帯で変わる。全国一律の月額は無い。

Right to Rent の share code に、確認したページは申請者側の手数料を書いていない。

銀行の口座維持費は銀行が決める。政府料金ではない。

## よくある質問

### 住所が決まるまで GP に登録できないか

恒久の住所が無くても、一時的な住所、または診療所の住所で登録できる、と NHS は書いている。一時的な患者としての登録は最長3か月で、その用紙は診療所にある。3か月後に、一時登録を再度出すか、恒久の登録をする。

### 銀行が無いと仕事を始められないか

公式の初日の案内は、給与のために銀行の詳細を雇用主へ渡す、と書いている。口座が無い状態で、その欄を埋められない。一方、National Insurance number は到着前でも就労を開始できる。口座と番号は、別の障害である。

### share code は一度出せばよいか

仕事と住居の例が挙がっている。同じコードを両方に使い回せる期間は、確認した eVisa の概要ページには日数が無かった。日数を断定しない。使う直前に発行する。

### スコットランドで家を借りるときも share code が必須か

Right to Rent の証明は、ウェールズ、スコットランド、北アイルランドでは不要と書かれている。家主が任意で在留資格を見たいと言うことと、この法的な証明義務は別である。

### 30日を過ぎたら手続きできないか

30日は公式の期限ではない。GP は到着後いつでも登録の対象であり、National Insurance number は働き始めるときに必要になる。Council Tax は住み始めた住居に対して発生する。30日を一日でも過ぎたから無効、とは書かれていない。
