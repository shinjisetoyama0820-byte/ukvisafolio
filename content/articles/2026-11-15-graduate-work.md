# 英国Graduateビザでできる仕事｜自営はできる、プロのスポーツはできない

> 編集用下書き。一次情報の確認と品質審査が終わるまで公開しない。

## 結論

2026年11月15日に確認した概要が、Graduate ビザでできることとして挙げているのは、ほとんどの仕事、仕事を探すこと、自営、条件を満たせばパートナーと子どもと英国で暮らすこと、外国へ出て英国へ戻ること、ボランティアです。

ボランティアは無給で、登録慈善団体、ボランティア団体、慈善やボランティア団体のためにお金を集める関連団体、法定の機関（例として Historic England）のいずれかです。

できないことは、給付（公的資金）の多く、または State Pension を申請すること、プロのスポーツ選手として働くことです。承認されると、一覧を受け取る、と概要は書いています。

確認日: 2026年11月15日。対象は、Graduate で英国にいる人。学生ビザの「自営はできない」とは別のビザです。この記事は Graduate だけです。

## 対象者と必要な準備

対象は、申請が承認された人です。承認の前に、自営を始めてよい、とは概要は書いていません。

週の時間数は、確認した概要にはありません。ほとんどの仕事、とだけ書いています。時間の上限をここには書きません。

## 必要書類

条件を見る場所は、承認後の一覧と eVisa です。求人の「卒業生可」を、ビザの条件の代わりにはしません。

学ぶことは、選ぶコースが学生ビザの対象でないときだけ、と概要は書いています。学生ビザの対象のコースなら、学生ビザを延長する側です。この就労の記事に、そのコースの判断は入れません。

## 手順

1. 承認の日を、仕事を始める前提の日にします。
2. 自営は、できることのリストにあります。学生ビザの自営禁止を、このビザへはコピーしません。
3. プロのスポーツ選手は、できないことのリストです。コーチという語は、確認したこの概要のできないことにはありません。学生ビザの概要にはコーチがあります。Graduate のできないことにコーチを足す、とはしません。
4. 給付と State Pension を、働いているから受け取れる、とは書きません。
5. 延長はできません。残るなら、別のビザへの切り替えがあり得ます。例は Skilled Worker です。切り替わるとは書いていません。

## 費用

申請料 £937 と、通常1年 £1,035 の IHS は、仕事の許可の追加料金ではありません。ボランティアを有給にすると、無給の文から外れます。
